# Help Desk Horror

**Status: In Development**

Help Desk Horror is a narrative horror game being developed in Unity with C#. The player works an evening shift at a university IT help desk, responding to technical support requests while the campus gradually becomes more unsettling.

What begins as a normal shift involving support tickets and routine technical problems slowly develops into something much more unusual.

This is an ongoing personal game development project.

---

## Game Concept

The player works the evening help desk shift from **4:00 PM to 9:00 PM** inside a university academic building.

Throughout each shift, the player handles IT support requests while exploring the building to resolve problems. Some requests are legitimate. Others may lead the player to places where something does not seem right.

As the nights progress, the university becomes increasingly unsettling and the story begins to reveal itself through the environment, support requests, and events occurring throughout the building.

The game is planned around **five nights**, with each shift advancing the narrative.

## Ticket System

The project originally began as a prototype focused on creating the game's IT ticketing system, which is why the local Unity project was originally named `TicketPrototype`.

Tickets contain information such as:

- User name
- User ID
- Email
- Reported issue
- Issue category

The ticket system serves as one of the game's primary ways of directing the player toward objectives and story events.

As development continued, the prototype expanded into the larger game project, including the university environment and narrative systems.

---

## University Environment

The game takes place primarily inside a fictional university academic building.

The environment currently includes multiple floors containing areas such as:

- Classrooms
- Computer labs
- Faculty and staff offices
- IT/help desk areas
- Hallways and other university spaces

The environment is being designed to transition from an ordinary university building into a more unsettling space as the story progresses.

## Project Structure

The repository contains the Unity source project:

- `Assets/` — Game scripts, scenes, models, materials, UI, audio, and other game assets
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings

Unity-generated directories such as `Library/`, `Temp/`, and `Logs/` are excluded from version control.
